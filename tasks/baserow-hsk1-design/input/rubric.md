# Rubric

Score 1-5 for each category:

1. Vocabulary tracking model: captures introduced, reviewed, underused, missing, and usage frequency.
2. Table design: clear Episodes, HSK Vocabulary, Episode Vocabulary Usage, Assets, and relationships.
3. Baserow usability: field types, views, labels, and visual workflow are practical.
4. API readiness: stable field names, slugs/IDs, payloads, and automation notes.
5. Isolation and evidence: uses only throwaway run target and writes required artifacts.
